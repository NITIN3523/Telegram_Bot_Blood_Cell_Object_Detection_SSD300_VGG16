# 🩸 Blood Cell Detection Telegram Bot using SSD300-VGG16

## 📌 Overview

This repository contains a **Telegram Bot** that uses a deep learning **object detection model** to identify and count blood cells in microscope images.  
The bot accepts blood sample images and returns a processed image with bounding boxes and count of:

- 🟢 Platelets  
- 🔴 Red Blood Cells (RBC)  
- ⚪ White Blood Cells (WBC)

Built using **SSD300 with VGG16 backbone**, this project demonstrates real-time medical image analysis via a Telegram interface.

---

## 📋 What's Inside?

- ✅ SSD300-VGG16 for blood cell detection
- ✅ Inference and bounding box visualization
- ✅ Telegram Bot integration (using `python-telegram-bot`)
- ✅ Live object detection with response image and count
- ✅ Modular and readable code structure
